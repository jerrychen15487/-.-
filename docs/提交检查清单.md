# 弦域·织音提交检查清单

报名页格式：视频 MP4/H.264、≤3 分钟、≤300 MB；技术文档 PDF、≤50 MB；全部代码 RAR、≤200 MB；作品全貌图 JPG/PNG、≤10 MB 且最多 1 张；开发板高清照片 JPG/PNG、单张 ≤10 MB 且最多 4 张；另有参赛作品承诺及使用授权书 PDF、≤50 MB。海报为选填。图文和视频均不得出现学校或指导老师身份信息。

- [x] 报告采用现有样机全景与各 HDMI 页面实拍；本轮不要求追加斜 45° 全景、接线近照或演奏中的频谱页。
- [ ] 按《三分钟演示视频分镜》拍摄和导出；检查实际编码、时长、大小、画面身份信息和同期音频。
- [x] 技术报告按官方模板的五部分编排，纳入现有实机、网站、完整时序和 RTL 代码图，并清楚区分示意图与实测图。
- [ ] 如最终报名表需要量化延迟或模拟输出频谱，再补充对应的仪器原图与测试条件。
- [ ] 代码包包含 FPGA 工程源、约束、仿真/测试、ESP32-S3 当前源码和编译配置；不包含构建缓存、旧备份、个人绝对路径、账号令牌、私人录音或第三方未授权素材。
- [ ] 网站代码由团队现有公开仓库单独维护，报名页 GitHub 链接可指向本作品总仓并从 README 链接原网站仓库；不要未经检查复制未提交的队友改动。
- [ ] 保留已实机确认的 2026-10-22 19:41 位流及配对时序报告、SHA-256；若 RTL 之后改动，必须重新布线和实测，不能沿用旧 Fmax。
- [ ] 准备双通道示波器和琴键动作触发点，测量琴键→PCM5102A LINE OUT 多次延迟。未测之前报告写“待测”。
- [x] 已推送至 `https://github.com/jerrychen15487/-.-`，本地与远端 `main` 提交哈希一致。
- [ ] 仓库目前未登录访问返回 404，提交报名页前须改为 Public 或按赛事规则为评委授权访问，并在未登录窗口复核。
- [ ] 承诺及授权书由参赛者本人核对并签署，Codex 不代签。

提交前核对 GitHub 仓库的评委访问权限、视频格式与时长、代码压缩格式及报名页各文件限制。
