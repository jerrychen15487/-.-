# 弦域·织音 技术报告

版本：2026-10-24 送审初稿。正文按报名页提供的报告模板组织；实物全景、开发板高清照片、完整端到端延迟测量仍须补入后才能作为最终提交版。报告不包含学校或指导老师信息。

## 摘要

弦域·织音以 Tang Mega 60K 为实时音源，面向低延迟、可持续表达的电子乐器演奏。USB-MIDI 电钢琴提供音符、力度和踏板事件；ESP32-S3 承担 USB Host、SPI/READY 桥接和 BLE 曲谱传输；演奏者另以摇杆、旋钮和按键调节弯音、颤音和八度。FPGA 内部由音符分配、频率／相位控制、ADSR、钢琴／风琴／加法音色、四声部混音、回声效果和 I²S 发送组成，逐样本计算音频，不播放预录 PCM。外置 PCM5102A 已由用户实机确认稳定出声，板载 PT8211 保留为对照声路；实际采样率为 48,828.125 Hz。钢琴音色在每个音频采样周期内对四个声部各计算至多 32 个加法分量，复用算术流水级完成分时运算；这是四复音、32 分量路线，而非 32 复音。HDMI 提供波形、频谱、真实曲谱五线谱／简谱和练习起音反馈，microSD 保存单首曲谱，网页通过 BLE 完成下载。2026-10-22 19:41 的实机位流配对报告给出系统域 Fmax 51.716 MHz、像素域 Fmax 29.585 MHz、setup/hold 违例端点 0/0。琴键动作至 DAC 模拟输出的整机延迟尚无双通道测量，故不宣称 ≤10 ms 或 ≤5 ms 已获证实。作品的主要价值是将确定性硬件音源、连续演奏表情及本地曲谱显示集成为一套可现场演示的系统。

## 第一部分 作品概述

### 1.1 功能与特性

系统从真实电钢琴接收音符、力度、踏板和音色选择；ESP32-S3 将 MIDI 事件编码为 6 字节 SPI 消息，经 READY 握手送入 FPGA。FPGA 在四个独立声部中分配音符，实时生成 P 钢琴、O 风琴、A 加法音色，支持 ADSR、弯音、CC1 颤音、四声部混音与可开关回声。音频同时走板载 PT8211 与外置 PCM5102A 标准 I²S。HDMI 可展示波形／频谱、四频测试、钢琴块及 SD 曲谱五线谱／简谱；练习模式显示起音判定、连击和计数。BLE 网页提供单曲下载和目录查询。

### 1.2 应用领域

适用于可编程电子乐器教学、FPGA 实时数字信号处理实验、交互式音频系统验证和曲谱辅助练习。当前样机以现成 USB 电钢琴保证稳定音符输入，同时由自接摇杆、旋钮和按键提供连续表情；电容触摸、超声测距与光电拨弦属于未接入的下一版自研交互方向，不能作为本版已实现功能。

### 1.3 主要技术特点

音频生成固定在 FPGA HDL 逻辑中，ESP32-S3 不合成或播放音频。四声部各有独立音符、频率／相位和包络状态。钢琴支路以一个正弦查表及乘法流水线在一个 1024 时钟的采样周期内分时处理四声部、每声部至多 32 个非整数拉伸分量；高音按 Nyquist 限制减少分量，避免混叠。I²S 每声道 32 位槽，前 16 位为有符号采样，PCM5102A 左右声道接收同一单声道混音。HDMI 的 64 点频谱用于演示四个异频基频，不等同于 32 条分量的仪器级证明。

### 1.4 主要性能指标

| 指标 | 当前证据与边界 |
|---|---|
| 基础复音 | 4 个独立声部；RTL 与实机演奏观察。未达到 32 音复音。 |
| 加法分量 | P 音色每声部至多 32 分量；A 音色单音 32 分量。需以长窗声卡频谱和 RTL 对照展示每条可闻分量。 |
| 采样率 | 50 MHz / 1024 = 48,828.125 Hz；这是计算与 RTL 时钟比值，非外部频率计实测。 |
| I²S | BCK 理论 3.125 MHz、LRCK 理论 48.828125 kHz；PCM5102A 已稳定发声，BCK/LRCK 尚无仪器截图。 |
| 时序 | 配对 2026-10-22 19:41 位流：sys_clk 51.716 MHz、pixel_clk 29.585 MHz，setup/hold 0/0。 |
| 整机延迟 | 尚未测量琴键动作到 PCM5102A 模拟输出；不能判定官方 ≤10 ms 或扩展 ≤5 ms。 |

### 1.5 主要创新点

1. FPGA 将四声部音色、包络、混音、回声和 DAC 发送整合为逐样本硬件通路，同时把 USB／BLE 通信职责与音频计算职责清晰分离。
2. 钢琴支路在有限资源下采用四声部 × 至多 32 分量的组内分时运算，保持每声部独立状态，而不把分量数误报为复音数。
3. 一套位流兼顾演奏、四频测试、曲谱阅读和练习起音反馈，现场可用音色、频谱、RTL 与时序报告交叉核对。

### 1.6 设计流程

先建立 MIDI 事件和四声部音源，再接入真实 USB 电钢琴、SPI/READY 与 FPGA 音频；随后加入摇杆表情、加法钢琴、回声和 HDMI 可视化。曲谱部分通过 BLE-UART 代理、FPGA microSD 单曲库及 PAGE/BITMAP 显示迭代。最后增加标准 I²S 到 PCM5102A，使用同版本仿真、布局布线报告和实机听音验证。完整端到端延迟及满载长期稳定性仍列为测量工作。

## 第二部分 系统组成及功能说明

### 2.1 整体介绍

```
USB-MIDI 电钢琴 ──USB──> ESP32-S3 ──6 字节 SPI/READY──> Tang Mega 60K FPGA
摇杆 X1/Y1/RP1、SW1/SW2 ──ADC/GPIO──> ESP32-S3       │
手机曲库网页 ──BLE──> ESP32-S3 ──UART v2──> FPGA ──SPI──> microSD
                                               │
                         四声部分配 → 逐样本音色/ADSR → 混音/回声
                                               ├──I²S──> PCM5102A → 有源音箱
                                               ├──串行音频──> PT8211
                                               └──视频时序/FFT/曲谱──> HDMI
```

ESP32-S3 是控制与文件传输桥，不参与采样值计算；FPGA 是完整音源。microSD 的曲目数据和 HDMI 曲谱阅读属于附加系统功能，不是预录 PCM 音频播放。所有声学输出均从实时波形算法产生。

### 2.2 硬件系统介绍

核心板为 Tang Mega 60K；ESP32-S3 USB Host 接入电钢琴，GPIO12/11/10 分别提供 SPI SCLK/MOSI/CS，GPIO13 接收 FPGA READY，双方共用 3.3 V 逻辑及公共地。曲谱全双工 UART1 用 GPIO17/18。摇杆 X1→GPIO1 为回中弯音，Y1→GPIO2 为瞬时颤音深度微调，RP1→GPIO4 为保持型深度旋钮；SW1→GPIO5、SW2→GPIO6 分别逐次降低／升高八度，范围 -4 至 +4。模拟输入只接 3.3 V 供电的摇杆，不能输入 5 V。

外置 PCM5102A 从 NEO Dock J8/PMOD1 接收 BCK、LRCK、DIN，模块 VIN 使用合适 5 V 电源，地与 FPGA 相连，线路输出接有源音箱。实物背面 H1L–H4L 焊桥的排障配置和方向见项目接线文档；任何修改须断电并以万用表通断测量确认。PCM5102A LINE OUT 插头曾出现接触不稳，现用户反馈已稳定发声，但故障点未单独实测定位。结构没有新制 PCB 或机械外壳，不将其写作自研机械成果。

### 2.3 软件及 HDL 系统介绍

FPGA 入口 `src/top.v` 连接 `spi_midi_frame_rx.v`、`poly_voice_ctrl.v`、`basic_dds_synth.v`、`piano32_poly_synth.v`、`additive32_synth.v`、`echo_delay.v` 和 `pcm5102_i2s_tx.v`。FPGA 的曲谱通路由 UART v2 控制器、SD 块设备、PSC2 PAGE 索引与缓存组成；视频通路由 640×480 时序、波形/64 点 FFT、五线谱/简谱页面与钢琴块练习叠加组成。`src/timing.sdc` 给 sys_clk 设置 20 ns 约束，并为显示 PLL 建立像素域时钟。

ESP-IDF 工程 `esp32_local/main/` 中，USB Host 解析 USB-MIDI 1.0 包，桥接器按 READY 状态排队发送 SPI 帧；Program Change 透传到 FPGA，摇杆产生 Pitch Bend 和 CC1，按键通过 MIDI 音高映射实现八度调整。BLE 和 UART 通路仅转发曲谱协议数据。网页提供曲目打包、BLE 设备连接和单曲下载；网页源码由团队的独立公开仓库维护，提交本作品时应链接原仓库并注明版本。

## 第三部分 完成情况及性能参数

### 3.1 整体实物与工程成果

实机已由用户确认：电钢琴经 PCM5102A 接有源音箱稳定出声，PT8211 声路正常；P/O/A 三音色可切换，A 音色可感知更多分量层次；五线谱、简谱和钢琴块练习反馈可显示。最终提交请配同一套接线的正面、斜 45° 全景、FPGA/ESP32/PCM5102A 高清近景与 HDMI 页面照片。现有文字记录与实机反馈不能替代提交页要求的照片。

### 3.2 特性成果与证据链

2026-10-22 19:41 封存位流 SHA-256 为 `8479F2EDF73ECB4C0DDF4F70C60168FD5C2534DA671C8F4F285C80270A318534`，同版本时序报告给出 sys_clk Fmax 51.716 MHz、pixel_clk Fmax 29.585 MHz、setup/hold 端点 0/0。RTL 使用 1024 个 50 MHz 时钟周期作为音频采样周期，推导 48.828125 kHz；这是设计参数证据，不是外部波形测量。四音测试模式生成 MIDI 55、62、69、76 对应不同基频，走与实琴相同的分配与音源路径。32 分量的独立频谱验证应录取低音单音的长窗 LINE OUT，列出预期和实测 1–32 次分量，并排除环境噪声、失真和混叠；HDMI 64 点频谱分辨率不足，不能单独作为此项证明。

GAO 的 SPI 片选到 FPGA 内部非零音频总线约 79.82 μs 属于局部链路；ESP32 回调到 SPI 完成统计也属于局部链路。两者不能简单相加推断完整琴键输入到模拟输出延迟。正式验收建议双通道示波器 CH1 接琴键动作触发器，CH2 接 PCM5102A LINE OUT，保持相同阈值多次采集，至少记录最小、最大、典型值和抖动；若没有示波器，本项维持“未测”。

## 第四部分 总结

### 4.1 可扩展之处

下一版可在现役可回退位流之外，增加 16 键电容触摸音阶、超声距离连续表情和单路对射光电拨弦；先核对 3.3 V 电平、传感器响应时间及标定，再实现 SPI 或 GPIO 输入映射。另可扩展真正 32 音复音、组并行算术单元和更高分辨率的频谱取证，但须重新评估 DSP/BSRAM、Fmax 和功耗。完成这些功能前不应写入当前版性能数字。

### 4.2 心得体会

项目中最重要的工程经验是把“音频能响”“代码具备通路”“时序报告通过”和“赛题完整指标有实测证据”分开。USB-MIDI 与 BLE 的包传输适合由 ESP32-S3 承担，音频逐样本生成仍应留在 FPGA。四声部 × 32 分量的方案展示了在采样周期预算内分时复用算术单元的资源取舍，也说明“分量数”“声部数”“独立振荡器数”不能混写。PCM5102A 的稳定出声建立了标准 I²S 到 DAC 的实机闭环；下一步应完成仪器级延迟、I²S 波形和长窗频谱取证，让性能表述与可复现实验一一对应。
