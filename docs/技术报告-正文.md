# 弦域·织音 技术报告

技术报告｜2026 年 11 月

## 摘要

弦域·织音将真实键盘演奏、FPGA 实时合成、曲谱管理与可视化组合成一套电子乐器。USB-MIDI 电钢琴提供音符、力度、延音踏板和音色事件；ESP32-S3 完成 USB Host 接入、SPI/READY 实时事件转发及 BLE 曲谱传输，摇杆、旋钮和双按键提供连续弯音、颤音深度与八度控制。Tang Mega 60K 中的 HDL 完成四声部分配、相位推进、包络、钢琴／风琴／加法音色、混音、回声和双路数字音频输出。钢琴支路为四个声部保存各自的分量相位，每声部最多计算 32 个加法分量，通过频率拉伸、分量权重、音头动态和带外分量抑制塑造钢琴音色。50 MHz 时钟每 1024 拍形成一个采样周期，对应 48,828.125 Hz；PCM5102A 和板载 PT8211 可输出同一实时生成的声音。HDMI 将波形、FFT 频谱、键盘反馈、五线谱、简谱和钢琴块练习连接到演奏过程。配套网站提供曲谱搜索、筛选、预览、导入与蓝牙下载，FPGA 从 microSD 读取 PSC2 曲谱用于显示和练习。2026-10-24 的布局布线报告显示系统域 Fmax 50.028 MHz、像素域 Fmax 25.811 MHz，setup/hold 违例端点均为 0。作品的核心是让 FPGA 的确定性逐样本运算直接服务于可演奏的音色和交互。

## 第一部分 作品概述

### 1.1 功能与特性

演奏者使用电钢琴完成选音、力度、踏板和音色切换，并以摇杆和旋钮连续塑造音高与颤音。ESP32-S3 将 USB-MIDI 事件经 READY 握手送给 FPGA。FPGA 在四个独立声部中分配音符，实时生成 P 钢琴、O 风琴和 A 加法音色；支持 ADSR、弯音、颤音、四声部混音及可开关回声。数字音频同时进入板载 PT8211 和外置 PCM5102A 标准 I²S 声路。HDMI 显示演奏波形、64 点 FFT 频谱、琴键反馈、四频测试、五线谱、简谱和钢琴块练习，练习画面叠加起音判定、连击与计数。网站完成曲库浏览、曲谱预览、`.pseq` 导入、设备目录查询和蓝牙下载。

### 1.2 应用领域

适用于可编程电子乐器教学、FPGA 实时数字信号处理实验、交互式音频系统验证和曲谱辅助练习。USB 电钢琴提供熟悉的演奏界面，摇杆、旋钮与按键增加连续表情；本地曲谱和练习反馈使合成引擎兼具演奏与学习用途。

### 1.3 主要技术特点

四声部各有独立音符、频率／相位和包络状态。钢琴支路采用 128 份分量相位状态，以共享正弦查表和乘法流水线在 1024 拍内完成四声部、每声部至多 32 分量的计算；高音依 Nyquist 界限缩减分量。包络和击键力度共同塑造发音动态。16 位有符号混音采样装入左右各 32 位的 I²S 槽，送至 PCM5102A；同一混音并行送至 PT8211。64 点 FFT 与 HDMI 页用于现场观察声音响应。

### 1.5 主要创新点

1. 四个声部各自保存相位、频率、包络和击键状态；钢琴支路再为每个声部保存最多 32 路分量相位，以采样周期内的硬件调度实现细致的频谱塑形。
2. 音色计算、实时效果、FFT 与 HDMI 共处一套 FPGA 位流，演奏者听到的声音与看到的波形、频谱和键盘状态由同一实时事件驱动。
3. 曲谱从网页经 BLE、UART 和 microSD 进入 FPGA，复用为五线谱、简谱及钢琴块练习数据，构成演奏、观察与学习的连续体验。
4. 标准 I²S 的 PCM5102A 与板载 PT8211 并行接收同一混音采样，使音源算法与数字音频接口能够分别展示。

### 1.6 设计流程

先建立 MIDI 事件与四声部音源，再接入 USB 电钢琴、SPI/READY 和音频输出；随后加入摇杆表情、32 分量钢琴、回声与 HDMI 可视化。曲谱经网站打包、BLE-UART 代理、FPGA microSD 存储和 PAGE/BITMAP 显示进入系统；最终接入标准 I²S DAC，并用仿真、布局布线报告和实机演奏交叉检查。

### 2.2 硬件系统介绍

#### 2.2.1 硬件整体介绍

核心板为 Tang Mega 60K；ESP32-S3 USB Host 接入电钢琴，GPIO12/11/10 分别提供 SPI SCLK/MOSI/CS，GPIO13 接收 FPGA READY，双方共用 3.3 V 逻辑及公共地。曲谱全双工 UART1 用 GPIO17/18。摇杆 X1→GPIO1 为回中弯音，Y1→GPIO2 为瞬时颤音深度微调，RP1→GPIO4 为保持型深度旋钮；SW1→GPIO5、SW2→GPIO6 分别逐次降低／升高八度，范围 -4 至 +4。模拟输入只接 3.3 V 供电的摇杆，不能输入 5 V。

外置 PCM5102A 从 NEO Dock J8/PMOD1 接收 BCK、LRCK、DIN，VIN 接 5 V 电源并与 FPGA 共地；LINE OUT 接有源音箱。板载 PT8211 同步输出，构成两条可对照的数字音频接口。

#### 2.2.2 机械设计介绍

样机以电钢琴作为完整力度键盘，Tang Mega 60K、ESP32-S3、摇杆、DAC 与有源音箱布置在演奏区周围。分体式构造使输入控制、合成核心、曲谱存储和音频输出的信号流清晰可见，也便于现场切换音色、页面和演奏模式。

#### 2.2.3 电路各模块介绍

USB 电钢琴接 ESP32-S3 的 USB Host；GPIO12/11/10 为 SPI SCLK/MOSI/CS，GPIO13 接 FPGA READY，GPIO17/18 为曲谱 UART。FPGA 的 `HP_BCK/WS/DIN` 连接板载 PT8211，`PCM_BCK/WS/DIN` 连接外置 PCM5102A；HDMI 输出画面，SD SPI 接口访问 microSD。摇杆 ADC 采用 3.3 V 电平。`top.v` 将上述接口明确分为演奏事件、曲谱传输、音频和视频四组，信号关系可由顶层端口逐一对应到实体模块。

### 2.3 软件系统介绍

#### 2.3.1 软件整体介绍

FPGA 入口 `src/top.v` 连接 `spi_midi_frame_rx.v`、`poly_voice_ctrl.v`、`basic_dds_synth.v`、`piano32_poly_synth.v`、`additive32_synth.v`、`echo_delay.v` 和 `pcm5102_i2s_tx.v`。FPGA 的曲谱通路由 UART v2 控制器、SD 块设备、PSC2 PAGE 索引与缓存组成；视频通路由 640×480 时序、波形/64 点 FFT、五线谱/简谱页面与钢琴块练习叠加组成。`src/timing.sdc` 给 sys_clk 设置 20 ns 约束，并为显示 PLL 建立像素域时钟。

ESP-IDF 工程 `esp32_local/main/` 中，USB Host 解析 USB-MIDI 1.0 包，桥接器按 READY 状态排队发送 SPI 帧；Program Change 透传到 FPGA，摇杆产生 Pitch Bend 和 CC1，按键通过 MIDI 音高映射实现八度调整。曲谱由团队网站提供：曲库页展示《天真》《进步》《阿拉贝斯克》的封面谱图、时长、节拍、音符数和文件大小，可搜索、筛选、预览与导入 `.pseq` 曲目包；设备页通过 Web Bluetooth 连接 ESP32-S3，查询板上目录并发送曲谱。网站 `Library.vue` 负责曲库搜索、筛选、卡片及预览交互，`useDevice.ts` 编排上传、续传与设备状态，`ble.ts` 实现蓝牙传输，`psc2.ts` 处理 PAGE/NOTE 等数据段及 CRC。曲目卡片同时标明五线谱、简谱和钢琴块三种呈现方式；左侧“发现曲谱／我的设备／使用指南”将选曲、设备管理和操作说明放在同一入口。网页源码由团队独立仓库维护。

#### 2.3.2 软件各模块介绍

**输入与分配。** `spi_midi_frame_rx.v` 将 SPI 串行帧还原为事件类型、通道、音符与力度；`poly_voice_ctrl.v` 为四个演奏声部优先分配空闲槽，重复 Note On 复用原声部，延音踏板 CC64 使松键后的音继续保持，满额时按轮转策略换声部。`top.v` 以 50 MHz 系统时钟每 1024 拍产生一次 `sample_tick`，所有音频采样逻辑共享该节拍。`basic_dds_synth.v` 依据 MIDI 音高生成相位步进，弯音因子乘法分级寄存；每个声部维护相位、力度、ADSR 状态。风琴预置使用正弦谐波叠加与持续包络。

**钢琴音色。** `piano32_poly_synth.v` 的 128 项 `phase_mem` 对应四声部各 32 个分量。每次 `sample_tick` 锁存四声部的频率、包络、力度与音符号，状态机按声部和分量次序执行相位读取、频率系数计算、正弦插值、权重修正和累加。分量频率使用带轻微拉伸的 `harmonic_multiplier()`；`partial_weight()` 设置各分量强度，音头与衰减中的高频贡献再由包络调制。`max_partial()` 随音高限制最高分量，控制带外成分。分量和经包络、力度缩放与 16 位饱和，得到四路独立钢琴采样。这是一条完整的周期内共享运算路径：音色计算的层次来自 32 分量，复音来自四份独立声部状态。

钢琴合成的关键并非播放一段固定波形，而是在每个采样点重新计算。`sample_tick` 到来时，`step_bus`、`envelope_bus`、`velocity_bus` 和 `note_bus` 同时锁存，避免同一采样点内各分量使用不同控制值。`{voice_index, partial_address}` 形成相位存储地址，因此相同编号的分量在四个声部中仍有独立的相位轨迹。`PHASE_READ` 读出旧相位，`PHASE_CALC` 用基础步进乘以预设的分量频率系数；重触发时使用 `phase_offset()` 建立音头相位关系。`SINE` 阶段对 64 点正弦表做插值，并写回下一采样点的相位；后续 `TONE`、`WEIGHT`、`ACCUM` 将正弦值依次乘以静态频谱权重和随包络变化的音色系数，再累加进当前声部。`LEVEL`、`VELOCITY`、`OUTPUT` 依次完成包络、力度和饱和输出。四个声部重复同一套系数和计算规则，因此合成音色保持一致。

音色参数体现了对钢琴声音结构的具体处理。`harmonic_multiplier()` 让较高分量的频率稍高于严格整数倍，模拟琴弦非理想刚性带来的谱峰拉伸；`partial_weight()` 用 32 组系数安排基波与高阶分量的相对强度，其中第 6、9 分量得到局部增强；`tone_factor` 让高频分量随音头和衰减改变贡献，低阶分量则保持主体音高。`max_partial()` 根据 MIDI 音高降低高音区的最高分量，避免分量越过采样率一半后折叠回可闻频带。128 份相位状态与共享运算链的组合，是本作品在音色层次、四声部独立性和 FPGA 资源之间的核心设计。

代码框 C：分量频率系数乘法、正弦／权重乘法和相位存储的共享硬件路径。

**基础 DDS、包络与风琴。** `basic_dds_synth.v` 在每个演奏声部内保存 32 位相位和独立包络状态，MIDI 音高决定基础相位步进，力度与包络决定输出幅度。正弦波来自 64 点查表及相邻采样插值；风琴将多个整数倍谐波合成，保持更稳定的持续段，并加入短促的触键瞬态。`top.v` 共享弯音系数给四个声部：14 位 Pitch Bend 经分段查表和插值转为频率因子，CC1 驱动三角波颤音并与弯音叠加，控制变化时维持声部相位连续。`poly_voice_ctrl.v` 处理 Note On、Note Off、重触发、满额换声部和 CC64 延音踏板，使演奏事件转成四路稳定的发声状态。

**加法音色、混音与回声。** A 音色由 `additive32_synth.v` 在一个采样周期内对 32 个分量逐项求和。`top.v` 按 Program Change 在钢琴、风琴、加法分支之间选择，同一组键盘事件可直接对比三种音色。四路采样先符号扩展求和，再算术右移两位给满额和弦留出幅度余量。`echo_delay.v` 使用 8192×16 位同步延时线保存历史采样，按开关将延时声叠加到干声；`audio_effected` 同时送到两路 DAC 和 FFT，因此听觉输出与频谱显示来自相同的效果后采样。

代码框 D：四声部求和、幅度预留和回声插入位置。

**音频接口。** `pt8211_tx.v` 将混音采样发送至板载声路；`pcm5102_i2s_tx.v` 独立产生标准 I²S 的 BCK、WS 与 DIN，左右声道均使用同一 16 位混音采样并填入 32 位时隙。两个发送器由同一 `audio_effected` 驱动，使数字音源与 DAC 接口能够并行核对。50 MHz / 16 形成 3.125 MHz BCK，64 个 BCK 构成一组左右采样帧，对应 48.828125 kHz。

[[SRC:top.v:497:509]]

代码框 E：板载 PT8211 与外置 PCM5102A 两条发送通路共用一个音频采样。

**频谱与 HDMI。** `fft64_spectrum.v` 对混音采样先做 16 点平均抽取，再采集 64 点并以六级基 2 FFT 计算；一套复数蝶形单元依次完成各级运算，输出 32 个幅值给频谱柱。`midi_visualizer.v` 显示演奏波形、频谱、音色标记和琴键反馈；波形区选择当前较响的声部，频谱区使用完整混音，因此和弦的多音关系仍能在频谱中看到。`video_timing_640x480.v` 生成像素坐标和同步时序，`video_pll.v` 产生像素与串行时钟，`dvi_tmds_encoder.v` 和 `dvi_tmds_phy.v` 将 RGB 像素送至 HDMI。`spectrum_test_pattern.v` 生成四个不同音高的测试事件，用于现场展示并发谱峰。

**曲谱与练习。** `score_uart_v2_transport.v` / `score_store_v2.v` 实现网站到板上的曲谱协议、目录和存储控制，`sd_spi_block_device.v` 以块读写访问 microSD。`psc2_page_index.v` 定位曲谱中的 PAGE/BITMAP 数据，`score_page_cache.v` 以 1 bit/像素将 640×480 谱页放进 38,400 字节缓存，`score_page_video.v` 将缓存字节映射成五线谱或简谱画面。`view_key_control.v` 识别单击切谱式、双击翻页、长按退出，页面请求和完成信号保证显示的是同一页数据。`psc2_note_stream.v` 与 `piano_preview_cache.v` 从曲目音符流生成钢琴块参考数据，`practice_onset_match.v` 将演奏起音和参考音符匹配，`practice_onset_stats.v` 汇总判定及连击，`practice_stats_video.v`、`practice_combo_video.v` 叠加到画面。网站预览、板上两类谱页和练习数据因此围绕同一份 PSC2 曲目组织。

## 第三部分 完成情况及性能参数

### 3.1 整体介绍

样机由电钢琴、Tang Mega 60K、ESP32-S3、摇杆控制区、PCM5102A、显示器与有源音箱构成。电钢琴提供熟悉的演奏动作，摇杆补充连续表情，FPGA 负责全部音频样本计算；网页、microSD 和 HDMI 将曲目数据带入演奏过程。各模块围绕琴键布置，形成可直接演奏、可观察合成过程的工作台。

[[IMG:system-overview.png]]

图 6 样机与各硬件模块的布置。

### 3.2 工程成果

#### 3.2.1 机械成果

电钢琴提供完整键盘尺度，FPGA、ESP32、DAC 与摇杆控制区布置在演奏者触手可及的位置。模块间采用可见连接，使电钢琴输入、硬件合成、音频转换和 HDMI 显示之间的关系一目了然。

#### 3.2.2 电路成果

电路链路从电钢琴 USB 输入开始，经 ESP32-S3 的 SPI/READY 桥进入 FPGA；FPGA 同时连接 PT8211、PCM5102A、HDMI 与 microSD。`top.v` 的 `spi_*`、`HP_BCK/WS/DIN`、`PCM_BCK/WS/DIN` 和视频端口分别对应这些实体接口。外置 DAC 使用标准 I²S，板载 PT8211 声路保留并行输出，便于音频对照。

#### 3.2.3 软件成果

HDMI 演奏页以 P/O/A 标记当前钢琴、风琴或加法音色，上半部显示主声部的时域波形，下半部显示完整混音的 FFT 频谱，底部琴键图形跟随演奏事件。演奏者可边听音色、边观察波形与频谱形状。图 7 展示页面布局。

### 3.3 特性成果

FPGA `top.v` 以 50 MHz 时钟和 1024 拍计数形成采样使能，设计采样率为 48,828.125 Hz。`poly_voice_ctrl.v` 管理四个演奏声部，`piano32_poly_synth.v` 为每声部在周期内计算至多 32 个加法分量，`pcm5102_i2s_tx.v` 输出标准 I²S。四音测试模式生成 MIDI 55、62、69、76 的不同基频；HDMI 的 64 点 FFT 对完整混音做实时频谱反馈。作品同时具备细致的钢琴音色、可演奏的多声部、标准数字音频接口和现场可视化。

## 第四部分 总结

### 4.1 可扩展之处

当前架构将演奏事件、声部状态、合成计算和显示存储分成清晰的模块。后续可沿相同接口接入电容触摸音阶、距离控制和光电触发，也可围绕共享分量运算路径增加算术并行度。现有的曲谱协议、页面缓存和起音判定为交互式练习提供了可继续扩展的数据基础。

### 4.2 心得体会

这套作品的设计重点是把演奏动作直接送进确定性的硬件音频通路。ESP32-S3 承担 USB-MIDI 与 BLE 等连接任务，FPGA 在固定采样周期内完成相位、频谱、包络、效果和音频发送。四声部各自的状态与 32 分量钢琴的共享运算路径相结合，让每个按键既保持独立的发声过程，又获得更丰富的音色层次。PCM5102A 标准 I²S、板载 PT8211、HDMI 频谱和曲谱练习共同把声音算法呈现为可听、可看、可操作的完整系统。
