# 弦域·织音三分钟演示视频分镜

成片要求：MP4，H.264/AVC，最长 3 分钟、300 MB 以内。画面和字幕不得出现学校、指导老师等与作品无关的身份信息。尽量同期录取 PCM5102A 的 LINE OUT，另用机位拍双手、板卡与 HDMI；不要用后配钢琴音冒充 FPGA 输出。参考视频的“全景—操作—结果”节奏可以借鉴，但不必模仿其低清晰度与长时间静态镜头。

| 时间 | 镜头与真实操作 | 同屏字幕／旁白重点 | 取证意义 |
|---|---|---|---|
| 0:00–0:12 | 全景：电钢琴、摇杆、ESP32-S3、Tang Mega 60K、PCM5102A、有源音箱和 HDMI 同框；现场弹一个音 | “USB-MIDI 输入，FPGA 实时合成，I²S DAC 输出” | 交代真实整机，不以软件画面代替硬件 |
| 0:12–0:30 | 简洁链路图叠加在实物连线特写：USB→ESP32→SPI/READY→FPGA→I²S→PCM5102A | “ESP32 负责输入与曲谱传输；音频逐样本计算在 FPGA” | 明确计算分工 |
| 0:30–0:58 | 固定机位演奏四音和弦，屏幕同时出现四音；切到 KEY2 四频测试片刻，再返回实琴 | “四声部独立状态、ADSR、混音；四个不同频率测试音” | 可闻复音与测试模式；HDMI 频谱仅是演示，不能证明 32 个独立谱峰 |
| 0:58–1:23 | 实琴音色键连续切换 P/O/A；每档弹同一短句，A 档停留一个低音 | “钢琴、风琴、32 分量加法音色；A 不是 32 复音” | 可听音色差异，与 RTL 计数口径一致 |
| 1:23–1:48 | 按住同一音，推 X1；调 RP1 形成持续颤音，再用 Y1 微调；松开 X1 回音高 | “弯音、可保持颤音深度与临时微调” | 展示可重复的连续表情映射 |
| 1:48–2:05 | KEY2 长按开启／关闭 FPGA 回声，用短音比较尾音；指示效果状态 | “回声由 FPGA 延迟缓冲实现” | 证明数字效果器不在音箱或电脑 |
| 2:05–2:30 | 手机网页 BLE 下载一首曲目，断网或断开网页后用 KEY1 展示五线谱、简谱和钢琴块练习判定 | “单曲 microSD 曲谱、离线阅读及起音反馈” | 展示区别于普通 MIDI 合成器的系统集成；只说实际验证的功能 |

| 2:48–3:00 | 回全景，弹结尾和弦；屏幕写“整机延迟待仪器实测”，如已有测量则替换为测法和最大值 | “不播放预录 PCM；端到端延迟按真实测量结果填写” | 诚实收尾，避免未测达标宣称 |

拍摄前确认 PCM5102A 插头已固定且不再靠掰动出声；有源音箱音量适中。每个功能先做 10 秒彩排，保留原始同期录音。代码、时序报告、现场画面使用同一已验证位流。若尚无示波器，不做 ≤5 ms 或 ≤10 ms 动画字样；将局部 GAO／日志耗时标为“部分链路”，不要相加冒充整机测量。
