# 弦域·织音：作品简介与关键词

## 作品简介

弦域·织音是我们以 Tang Mega 60K 为核心制作的一套 FPGA 表情电子乐器。电钢琴提供音高、力度、延音踏板和音色选择，摇杆、旋钮与八度按键让演奏动作连续改变弯音和颤音。ESP32-S3 接入 USB-MIDI 电钢琴，并将演奏事件经 SPI/READY 送进 FPGA；它还通过蓝牙连接配套曲谱网站，完成曲目传输。音频样本的生成留在 FPGA 中，由 HDL 实时完成。

合成引擎为四个演奏声部分别保存音符、频率、相位和包络状态，提供钢琴、风琴与加法三种音色。钢琴声部各有最多 32 个加法分量：独立相位、轻微拉伸的分量频率、经过设计的谱峰权重和随包络变化的高频贡献，共同塑造琴键落下后的音头与衰减。FPGA 在每个采样周期内完成分量运算、四声部混音和回声处理，声音由标准 I²S 送至 PCM5102A DAC，同时输出到板载 PT8211。系统时钟为 50 MHz，每 1024 拍形成一个采样点，对应 48,828.125 Hz 音频采样率；声音由实时运算生成，不依赖预录 PCM 片段。

HDMI 将演奏波形、64 点 FFT 频谱和琴键状态呈现在同一画面，并能切换到五线谱、简谱和钢琴块练习。配套网站支持曲谱搜索、筛选、预览和曲目包导入，通过蓝牙把曲目送至板上 microSD；FPGA 读取同一份曲目数据，用于谱页显示和演奏判定。我们把演奏输入、逐样本合成、数字音频输出、曲谱管理与可视化连成一条完整的硬件演奏链路，让音色结构既能被听见，也能在屏幕和 RTL 中被直接观察。

## 三个关键词

FPGA 实时音频合成；32 分量加法音色；多维演奏表情
