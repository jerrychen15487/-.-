# 弦域·织音：作品简介与关键词

## 可直接粘贴到报名页的作品简介

弦域·织音是一套以 Tang Mega 60K FPGA 为实时音源的电子乐器系统。演奏者用 USB-MIDI 电钢琴输入音符、力度和踏板动作，用自接摇杆及旋钮连续控制弯音与颤音，并用两个按键调整八度。ESP32-S3 只负责 USB-MIDI 接收、控制事件桥接和曲谱蓝牙传输；音符分配、逐样本合成、ADSR 包络、四声部混音、回声效果及音频发送均在 FPGA 的 HDL 逻辑中完成，不播放预录音频。

当前系统提供钢琴、风琴和加法合成三种音色。其中钢琴音色以四声部、每声部至多 32 个加法分量逐样本计算，分量运算在一个采样周期内分时完成；这不是 32 音复音，也不是 32 个独立物理振荡器。音频以约 48.828 kHz 的实际采样率经标准 I²S 送至 PCM5102A DAC，同时保留板载 PT8211 声路。HDMI 可展示波形、频谱、曲谱与钢琴块练习反馈；FPGA 还支持 microSD 曲谱存储和蓝牙网页单曲下载。已有实机演奏、I²S DAC 出声、曲谱显示等观察及 RTL／时序证据。完整琴键动作到 DAC 模拟输出的延迟尚待双通道仪器实测，因此不将 ≤10 ms 或 ≤5 ms 写作已达标结论。

## 三个关键词

FPGA 实时音频合成；32 分量加法音色；多维演奏表情

## 与旧简介的关键差异

- 旧简介中的电容触摸、光电拨弦、压力和超声测距尚未接入现役版本，只能列为后续设计，不写成已完成。
- 现役架构是 USB 电钢琴／摇杆 → ESP32-S3 桥接 → FPGA 合成 → I²S／DAC，不是 FPGA 直接采集全部传感器。
- 已有四声部与 32 分量音色，但没有 32 复音；不能据此填写“32 个独立振荡器 × 48 kHz = 153.6 万振荡器样本每秒”。
- 实际采样率为 50 MHz ÷ 1024 = 48,828.125 Hz，不是精确 48,000 Hz。
- RTL 中未发现已接入的物理弦建模或 FM 音色单元，不能把两者写为当前合成通路。
- 端到端延迟尚无双通道实测结果。SPI 内部或 ESP32 局部耗时不等同于完整琴键至 DAC 延迟。

## 后续自研交互设想，暂不计入当前参赛版

可选 16 键电容触摸模块作音阶阵列；已有超声波模块可尝试距离连续控制；光电拨弦可先以一组对射红外光电门测试遮挡沿和拨动速度。三者都必须完成电气接线、信号采集、去抖／标定、映射、实机演奏和延迟取证后，才能移入“已实现”介绍。现有电钢琴与摇杆版本应保留为可回退基线。
