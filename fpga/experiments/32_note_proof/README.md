# 32 音证明模式源码

这是 2026-10-24 本机 FPGA 工程的后续实验，不是主目录中 2026-10-22 已确认出声位流的配套源码。这里保存相对主目录不同的工程文件及新增模块；其他 RTL、约束与仿真文件沿用 `fpga/` 主目录。单独编译实验版本时，将此目录中的对应文件覆盖到 `fpga/` 的相同相对路径，再重新运行 Gowin 综合和布局布线。不要将主目录的封存位流与此实验源码混用。

`poly32_light_synth.v` 是独立的 32 音轻量证明模式，和主目录的四声部、每声部最多 32 加法分量钢琴音色是两种不同结构。`poly32_partial_scheduler.v` 只是 32×32 分量调度器草案，没有接入音频引擎。此次实验不代表 32 个一致钢琴音色的实机演奏能力。

本机原工程 2026-10-24 19:00 的静态时序报告显示：sys_clk Fmax 50.028 MHz，pixel_clk Fmax 25.811 MHz，setup/hold 违例端点 0/0。报告位于原工程 `impl/pnr/midi_basic_synth_tr_content.html`；实验模式未随主目录封存位流一起验证上板。
